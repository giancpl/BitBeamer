# Studio library sources and metadata

| Edit | Purpose |
| --- | --- |
| `studio/<id>.tex` | One current editable composition |
| `studio/shared/` | Geometry shared by retained original colour pairs |
| [index.json](index.json) | Field definitions, measured boxes, graphic dependencies and aliases |
| [models.json](models.json) | Grouped models, variants, original palettes and semantic mappings |
| [review.json](review.json) | Notes, status, ordered selection and examples |
| `measurements.json`, `figma-inventory.json`, `default-content-audit.json` | Technical history and provenance |

Compatibility aliases share current sources. Original references remain maintenance
data; neutral content stays the default. [Ready-content examples](EXAMPLES.md) recover
the retained English text and graphics through explicit field overrides.
[The reusable shortlist](REUSABLE.md) starts with title, contents and closing. Palette switches use only original versions.

`EXAMPLES.md`, `REUSABLE.md`, `MODELS.md`, `MIGRATION.md`, `REVIEW.csv`, `CATALOGUE.md`, `SELECTION.md` and
`studio/registry.tex` are generated by `python3 scripts/review.py sync`.
The same command updates usage guides, gallery pages and the selected showcase.
Compile one changed composition with `review.py slide <id>`; verify consistency
without writes with `review.py check`.

Start with [grouped models](MODELS.md) to use a slide. See [the review workflow](../docs/STUDIO-COLLECTION.md)
to refine one, or [the repository map](../docs/STRUCTURE.md) for the wider structure.

## Small graphical review batches

`review.json` also records ordered `review_batches` of one to five existing
composition IDs, including registered fixed slides. Start with `covers-01`;
team, contents and closing follow separately. Use the batch selector in the
[unified slide guide](../docs/slides/index.html) and the
[review workflow](../docs/STUDIO-COLLECTION.md#review-one-small-family-at-a-time).
Batch membership never changes review status or duplicates a layout source.
