\section*{One command works for every icon}
\begin{tabularx}{\textwidth}{@{}m{22mm}X@{}}
\bbIconRow{alice-and-bob}{\asset[width=2cm]{alice-and-bob}}
\bbIconRow{qrcode-one}{\asset[height=1cm]{qrcode-one}}
\end{tabularx}
Use \bbSheetCode{\asset{name}} for names containing hyphens or digits, and whenever
a shortcut conflicts with an existing LaTeX command. Existing commands are
never replaced.

\section*{Sizing and rotation}
\begin{tabularx}{\textwidth}{@{}lX@{}}

\bbSheetCode{\cow[width=3cm]} & Set a fixed width. \\
\bbSheetCode{\bitcoin[height=1em]} & Match the size of surrounding text. \\
\bbSheetCode{\asset[width=2cm,height=1cm]{cow}} & Fit inside a box, keeping proportions. \\
\bbSheetCode{\asset[height=1cm,angle=15]{key}} & Rotate the artwork. \\
\end{tabularx}

    \centering
    \alice[height=1.5cm]
  \end{column}
  \begin{column}{0.45\textwidth}
    \centering
    \bob[height=1.5cm]
  \end{column}
\end{columns}
\end{verbatim}
The rendered pair above illustrates the placement; the code uses Beamer columns.

\section*{Colour and troubleshooting}
\begin{tabularx}{\textwidth}{@{}p{38mm}X@{}}
\toprule
\textbf{Question} & \textbf{What to do} \\
\midrule
Why does text colour not change the icon? & The supplied PDFs contain their own colours. Prepare a recoloured artwork variant when needed. \\
An icon name has a hyphen & Use the generic command, for example \bbSheetCode{\asset{qrcode-one}}. \\
A shortcut already exists & Use \bbSheetCode{\asset{name}}; the library preserves existing commands. \\
An icon is missing & Check its name in the catalogue and confirm the prepared file is present. A missing icon produces a placeholder and warning. \\
Artwork changed locally & Run \bbSheetCode{scripts/prepare-assets.py}, then regenerate the catalogue before sharing the project. \\
\bottomrule
\end{tabularx}
