# Examples and generated catalogues

Build from the repository root: `python3 scripts/build.py examples/<name>.tex`.
Outputs go to `build/`. On Windows use `py -3`; add `--backend native` for local TeX.
For your own deck, copy [start-studio.tex](../start-studio.tex) or
[start-academic.tex](../start-academic.tex) to the root.

| File | Purpose | Source to edit |
| --- | --- | --- |
| [assets-example.tex](assets-example.tex) | Simple icon usage | This file |
| [icon-cheatsheet.tex](icon-cheatsheet.tex) | Printable icon syntax guide | This file |
| [cover-layouts.tex](cover-layouts.tex) | Academic cover orientations | This file |
| [asset-catalogue.tex](asset-catalogue.tex) | Complete icon reference | Artwork and metadata; run `build-asset-catalogue.py` |
| [studio-closing.tex](studio-closing.tex) | QR on/off closing variants and custom text | This file |
| [studio-team.tex](studio-team.tex) | Cover, team introduction and contents, with editable statistics | This file |
| [studio-agendas.tex](studio-agendas.tex) | Four- and five-item agendas, neutral and ready-content examples | This file |
| [studio-customization.tex](studio-customization.tex) | Text, icon, image and file substitutions | Generated from the current field contracts |
| [studio-reusable.tex](studio-reusable.tex) | Neutral title, contents and closing shortlist | `reusable_selection` in `templates/review.json`, then `review.py sync` |
| [studio-ready-content.tex](studio-ready-content.tex) | Full editable English content examples; compile explicitly | Retained content history and current layouts, then `review.py sync` |
| [studio-selected-templates.tex](studio-selected-templates.tex) | Working Studio selection | `templates/review.json`, then `review.py sync` |
| [studio-model-catalogue.tex](studio-model-catalogue.tex) | One representative per grouped model | `templates/models.json`, then `review.py sync` |
| [studio-template-catalogue.tex](studio-template-catalogue.tex) | Every retained composition | Current sources and metadata, then `review.py sync` |
| [studio-review-index.tex](studio-review-index.tex) | Full collection index | Generated by `review.py sync` |
| `code/`, `data/` | Small code and chart inputs | These files; values are illustrative |

Use `review.py models --open` for the lightweight model PDF. Use `review.py all`
explicitly for the full vector archive. Generated examples are marked in their
first comment; copy them before writing a personal presentation.

See [the model guide](../docs/STUDIO-MODELS.md), [icons](../docs/ICONS.md) and
[repository map](../docs/STRUCTURE.md).
